# sliceline

Slice filesystem line paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/sliceline/

## Install / run

```bash
git clone https://github.com/theworker02/sliceline.git
cd sliceline
node src/cli.js
node --test
```
